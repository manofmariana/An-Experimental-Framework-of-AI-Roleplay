# 改动指向地图

新文件必须先在此登记（路径 / 职责 / IO / 依赖方向），再写码。职责变化时同步更新本表。顶层目录布局见 AGENTS.md 目录结构段；依赖禁止边由 `scripts/check-dependencies.ts` 机械守护（`npm run test:arch`）。
