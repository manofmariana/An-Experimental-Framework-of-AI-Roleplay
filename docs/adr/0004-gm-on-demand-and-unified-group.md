# GM 按需激活与同步组单变量化（M2-b）

M2-a 的核心循环是"每个连续圈结束 GM 必裁决一次"。M2-b 设计冻结时反转了它：**无判定是轮的默认形态，GM 激活是例外**——一个行动周期（连续场景内所有成员各行动一次）内无人立 GM 请求标记，整圈不经过 GM；触发只有两种：标记触发（同先攻批全员行动完后立即激活）与硬保险（距上次激活满 N 个行动周期，周期末激活，N 为配置项）。动机：擦桌子、抬头看一眼类行为不该占用 GM 判定开销；"对话轮只许说话"又损失场景表现力——于是对话轮概念整体废除，说话就是普通行动，唯一约束是"无判定"。

配套地，**inScene/inTalk 双变量合并为单 Group 变量 {组编号， 组位置}**：对话组（远程联系）不再是一种组类型，而是"邀请并入普通组"——成组 = timer+location 一致（自动）+ 邀请跨地点并入（接受即 timer 归 0 入组，拒绝自动还原）；组位置绑定先攻最高者 CID，入组位置不同先攻 -1。感知过滤因此不在组层做（AV 标签位方案撤回），M2-b 期间组内注入全透传，跨地点私密性推迟给 P2 的顶层 TAG 过滤系统。

**Considered Options**：① 周期末统一激活（被否——开门类判定不能等，否则其他角色基于未裁决状态继续行动）；② 逐角色混合判定（被否——GM 仍会被任何一人的判定请求拖着频繁激活，且判定上下文割裂）；③ 保留对话组叠加层 + AV 标签位（被否——双变量叠加态要在调度器里永久保留"对话模式"特例，AV 过滤与 P2 TAG 系统功能重复）。

**Consequences**：角色离场不再必经 GM（离开标记 = 程序化归 0 + 超大 timer，下次 GM 统一结算；"玩家离场立 GM 请求"例外曾短暂存在，已废除——所有角色统一程序化，离场者过去言行继续注入原组直到清算，后续角色经 departure_notices 占位符获知）；先攻变量结构化为 {先攻值，组编号}（组编号变化即重置，归 0 除外——召回复用）；存档 characters.json 结构变更（group/initiative 替换 inScene/inTalk/initiative），旧档按"版本不符即拒绝"原则不迁移。后续补充（同会话）：**邀请延迟生效**——联系标记触发 GM 立即结算（双方看不到标记），邀请者组下次回前台才激活受邀者，结构性消除"邀请抢在受邀者旧组行动之前"的时钟抢跑；配套**频道变量**（邀请发起即分配、拒绝失去、退组清除；防重入 + 全同地自动清理）。
