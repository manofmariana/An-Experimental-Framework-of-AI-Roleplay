# 变量 TAG：末端级过滤与同结构 TAG 附加文件

**决定**：变量树的过滤粒度为末端。末端判定式 = **复合结构类型（对象/记录）且所有直接属性均为原始类型（number/string/boolean/string_list/tag_list）→ 末端类型，其实例 = 末端**——静态判定，只看模板声明、与实例形态无关。变量树上有且仅有一种末端类型 = **{value, tags, formula?} 外壳**：模板不存在裸原始属性（`name: string` = `name: 外壳(string)` 简写），自定义类型的直接属性必为复合（外壳或类型引用），其实例 = 容器。tags = tag_list = {name, level} 数组原子值，值元素不是树节点——tags 套 tags 的递归在定义上不存在。逐末端按其 TAG 集（自带 ∪ 附加文件赋予）求值，挂载形态 {name, level}、判定式见 adr/0007。TAG 附加走**同结构附加文件**（与变量模板同构；节点级条目向下级联到每个末端、末端级条目只挂该末端；按模板末端位置解析映射到实例，不做运行时递归；世界包定义，运行期经 WebUI/工具 Agent 扩充），CID 类 TAG 按属主分发（每角色仅自身 CID 一个）。调用路径必须解析到末端实例：裸路径默认取 value（`.value` 显式同义），`.tags` 字段选择子原子返回 TAG 列表（一般仅 GM 视角/程序向占位符使用）；路径不得穿越末端（tag_list 值元素不可寻址）。过滤求值对象 = 路由链末端实例的 tags 属性，与字段选择子无关。渲染侧失败语义见 adr/0008。过滤流程 = 声明调用路径 → 逐末端遍历过滤 → 逐末端 {status, content, matched} → 遍历渲染 → 身份替换 → 组装注入。

**为什么**：单一挂点全量返回无法表达"同类可认知中存在个别秘密字段"（角色持有自己不了解效果的物品）；路径过滤/内容过滤二分制造死局（神秘石头场景：能过内容过滤的过不了路径过滤，反之亦然）——结构 TAG 必须挂给具体内容（末端）而非路径，每个末端独立判定、独立降级（"未知装备"）。末端类型唯一化（外壳即末端类型）让"末端身份由模板静态声明"有了判定式：属性全原始值型即末端，与实际数据形态无关；tags 作为外壳的原始值型字段而非子节点，递归无处发生。

**代价**：快照体积与注入 token 上升；附加文件与变量模板须保持同构（校验负责）；占位符编辑复杂度上升（逐路径失败语义 + 组合匹配校验）。
