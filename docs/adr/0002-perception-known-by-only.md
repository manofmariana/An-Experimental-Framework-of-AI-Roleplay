# 事件感知只走 known_by 标签

M2 之前，事件的可见性判定有两条通道：`known_by` tags + location 匹配（simulator.ts 的双重过滤）。M2 定为：事件能且只能携带 `known_by` tags——GM 标记时已基于推理考虑了各角色的可视情况（谁在场、谁参与对话、私密事件只标自己），location 只是叙事记录字段，不参与感知过滤。跨场景对话事件因此无需任何特殊处理（不存在"地点不符导致看不到自己参与的对话"的问题）。

代价：可见性质量完全依赖 GM 的标记纪律与提示词约束，程序不再做机械兜底。这与"GM 是真相层唯一写入者、且 GM 在全员行动完后才推理"的架构前提一致。
