# 计时器是唯一时间跨度设置单元（耗时概念废除）

M2 连续时间 DES 中，时间跨度曾有两个概念：耗时（duration，只推进时钟，无激活功能）与计时器（到期激活角色/组）。多同步组交替行动时纯耗时会出错：A 组 8:00 行动并设 1h 耗时，B 组 8:30 行动并设 1h 耗时，时钟直接跳到 9:30——A 组 9:00 的第二次行动被吞掉。因此废除耗时概念，计时器（时间轴坐标）是唯一时间跨度设置单元：GM 通过在时间轴上订立坐标安排未来轮次，调度器激活最近坐标实现时间推进。渲染层时间近似连续（最小单元 1 分钟，{y/m/d/h/m}），逻辑层离散（坐标序列即轮次顺序）。

已知风险：多个同步组的事件交替记录，既可能让 GM 的故事安排更好，也可能干扰 GM 判断——待实际运行验证。
