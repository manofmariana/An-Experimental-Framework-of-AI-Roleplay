# 计时器是唯一时间跨度设置单元

**决定**：时间跨度只由计时器表达——GM 在时间轴上订立到期坐标，调度器弹出最近坐标推进时间。渲染层时间近似连续（最小单元 1 分钟，{y/m/d/h/m}），逻辑层离散（坐标序列即轮次顺序）。

**为什么不设"耗时"（duration）概念**：耗时只推进时钟、无激活功能，多同步组交替行动时会吞行动——A 组 8:00 行动并推进 1h 耗时，B 组 8:30 行动再推进 1h，时钟直接跳到 9:30，A 组 9:00 应发生的第二次行动被跳过。计时器把每个未来行动锚定在时间轴坐标上，弹出顺序即轮次顺序，结构上不存在被吞的可能。

**已知风险**：多个同步组的事件交替记录，既可能让 GM 的故事安排更好，也可能干扰 GM 判断——待实际运行验证。
