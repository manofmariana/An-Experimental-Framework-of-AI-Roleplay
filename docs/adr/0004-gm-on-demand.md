# GM 按需激活（无判定轮）

**决定**：无判定是周期的默认形态，GM 激活是例外。一个行动周期内无人立 GM 请求标记，整周期不经过 GM；触发只有两种：标记触发（同先攻批全员行动完后立即激活）与硬保险（距上次激活满 N 个行动周期，周期末激活，N 为配置项）。说话就是普通行动，唯一约束是"无判定"，不设"只许说话"的对话轮。

**为什么不每周期必裁决**：擦桌子、抬头看一眼类行为不该占用 GM 判定开销；"只许说话"又损失场景表现力。

**为什么标记触发是立即激活而非等周期末**：开门类判定不能等——否则其他角色会基于未裁决状态继续行动。"逐角色混合判定"也不取：GM 仍会被任何一人的判定请求拖着频繁激活，且判定上下文割裂。
