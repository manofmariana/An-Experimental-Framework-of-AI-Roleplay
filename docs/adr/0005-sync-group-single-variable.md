# 同步组单变量化（Group 变量与邀请并入）

**决定**：组归属用单 Group 变量 {组编号， 组位置}。远程联系不是独立的组类型，而是"邀请并入普通组"：成组 = timer+location 一致（自动）+ 邀请跨地点并入（接受即 timer 归当前时钟（立即到期）入组，拒绝自动还原）；组位置绑定先攻最高者 CID，入组位置不同先攻 -1。感知过滤不在组层做，组内注入全透传，跨地点私密性归规划中的顶层 TAG 过滤系统（见 ROADMAP）。

**为什么不要"在场/通话"双变量叠加 + AV 标签位**：叠加态要在调度器里永久保留"对话模式"特例；AV 过滤与顶层 TAG 过滤系统功能重复。

**配套机制**：离开标记 = 程序化组归 0 + timer 置 null（无计时器，调度不再弹出），下次 GM 统一结算（所有角色含玩家统一程序化；离场者过去言行继续注入原组直到清算，后续角色经 departure_notices 占位符获知）；先攻变量结构化 {先攻值，组编号}（组编号变化即重置，归 0 除外——召回复用）；邀请延迟生效——联系标记触发 GM 立即结算（双方看不到标记），邀请者组下次回前台才激活受邀者，结构性消除"邀请抢在受邀者旧组行动之前"的时钟抢跑；频道变量——邀请发起即分配、拒绝失去、退组清除，承担防重入与全同地自动清理。
