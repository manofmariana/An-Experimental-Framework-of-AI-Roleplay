# 正文指称占位符 [[称呼|@CID]]

正文不只是显示层产物，还是角色/GM 的注入素材（正文滑窗）。这给正文的身份写法出了个两难：裸名直存会破坏认知隔离——NPC 没在 relations 里记录过的人，读正文也白得名字；裸 @CID 直存则杀死表达力——外号、别称、特征称谓（"鞋上有青苔的男人"）全部没法用。

定为：正文存带 `[[称呼|@CID]]` 占位符的原文（称呼 = 当时为人所知的名字/外号/特征；被引号包裹的直接引语豁免，照写原文），渲染按读者分视图——玩家显示 → 称呼；角色注入 → 按读者 relations（name → impression → 保留 @CID）；GM 注入 → 称呼（@CID）；正文 agent 自己的上一轮正文注入保持原文（它要从原文学习占位符格式）。这与事件的 @CID 存储 + renderForReader 是同一套"存储用 CID、渲染看读者"体系，正文由此纳入统一标准。

代价：占位符合规是提示词协议层约束，不做程序强校验——正则不匹配即原样保留，不报错不阻塞；显示层（前端）与注入层各承担一次机械替换。
